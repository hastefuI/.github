# GitHub

GitHub for [@hasteful](https://github.com/hastefuI) 🐇

## Environment

The repositories that set up and carry my personal environment.

- 🐇 [dotfiles](https://github.com/hastefuI/dotfiles) shell, editor and tool
  configuration, installed by symlink.
- 🍺 [homebrew-tap](https://github.com/hastefuI/homebrew-tap) the Homebrew tap
  that installs my tools.
- 🤖 [skills](https://github.com/hastefuI/skills) Agent Skills shared across
  the coding agents I use.
- ⌨️ [uhk-macros](https://github.com/hastefuI/uhk-macros) macros I've created
  for the Ultimate Hacking Keyboard.

## Projects

### Ultimate Hacking Keyboard

- 🧹 [uhkm](https://github.com/hastefuI/uhkm) lint and format Ultimate Hacking
  Keyboard Macro files.
- 📐 [uhkm-spec](https://github.com/hastefuI/uhkm-spec) an unofficial file
  format specification for Ultimate Hacking Keyboard Macros.
- ⌨️ [awesome-ultimate-hacking-keyboard](https://github.com/hastefuI/awesome-ultimate-hacking-keyboard)
  awesome things related to the
  [Ultimate Hacking Keyboard](https://ultimatehackingkeyboard.com).

### Security And Privacy

- 🎲 [diceware](https://github.com/hastefuI/diceware) a TUI-inspired Diceware
  passphrase generator, in Go.
- 🎭 [ffrelayctl](https://github.com/hastefuI/ffrelayctl) a CLI for
  [Firefox Relay](https://relay.firefox.com).
- 👨‍🚀 [astro-sniffle](https://github.com/hastefuI/astro-sniffle) a Proof of Concept (PoC)
  demonstrating scaffold-time command injection in [Astro](https://astro.build)'s `create-astro` CLI.
- 👤 [awesome-auth0](https://github.com/hastefuI/awesome-auth0) awesome things
  related to [Auth0](https://auth0.com).
- 🫂 [awesome-proxy-piercing](https://github.com/hastefuI/awesome-proxy-piercing)
  awesome things related to proxy piercing.

### CLI

- 🔁 [recall](https://github.com/hastefuI/recall) a CLI to cache and recall command
  results with a TTL.

### Patches
- 🧵 [irssi-user-hostname-servername](https://github.com/hastefuI/irssi-user-hostname-servername)
  an [Irssi](https://irssi.org) patch that makes the `USER` command's hostname
  and servername configurable.

### Art And Music

- 🗝️ [analog-gothic](https://github.com/hastefuI/analog-gothic) a free 1-bit
  pixel icon kit inspired by medieval symbolism and nature.
- 💿 [discogs-dataset-genres-styles](https://github.com/hastefuI/discogs-dataset-genres-styles)
  genres and styles from the [Discogs](https://www.discogs.com) data dump,
  published as an NPM package.
